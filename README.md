# PEAPChapter

Code for figures for 'differentiating periodic &amp; aperiodic' signals chapter.

[![Chapter](https://img.shields.io/badge/DOI-10.1007/978--3--031--20910--9_22-informational.svg)](https://doi.org/10.1007/978-3-031-20910-9_22)

## Contents

This repository contains the code that create the figures that were included in the chapter on differentiating periodic & aperioduc signals. 

Each figure has a dedicated notebook, within the `notebooks` sub-folder.

## Reference

This repository relates to the 
`How Can We Differentiate Narrow-Band Oscillations from Aperiodic Activity?` chapter that appeared in the 
`Intracranial EEG: A Guide for Cognitive Neuroscientists` textbook.

The full reference is:

    Donoghue, T., Watrous, A.J. (2023). How Can We Differentiate Narrow-Band Oscillations from Aperiodic Activity?.
    In: Axmacher, N. (eds) Intracranial EEG. Studies in Neuroscience, Psychology and Behavioral Economics. Springer, Cham.
    https://doi.org/10.1007/978-3-031-20910-9_22

Direct Link: https://doi.org/10.1007/978-3-031-20910-9_22

This chapter is also available as an open-access preprint:
https://doi.org/10.31234/osf.io/k6nhd

## Requirements

This project was written in Python 3 and requires Python >= 3.7 to run.

This project requires the following dependencies:

 - [fooof](https://github.com/fooof-tools/fooof)
 - [neurodsp](https://github.com/neurodsp-tools/neurodsp)
 - [mne](https://github.com/mne-tools/mne-python)
